Yahoo API Playground<br/><br/>Most of the Yahoo API's deliver data in XML or JSON formats which is very helpful to end users. I was trying out various YAHOO! tools and found Yahoo GeoPlanet useful. The documentation is very detailed and helpful if you are developing something..  Let me give some examples..<br/><br/>If you want to get latitude and longtude of a place or reverse calculate it?<br/>Try these directly..  (Thanks to GeoPlanet API's)<br/><br/>&nbsp;<br/><ol><br/>	<li>http://where.yahooapis.com/geocode?q=19+Howard+Road,+Southampton,+Hampshire</li><br/>	<li>http://where.yahooapis.com/geocode?q=50.914716,-1.417612&amp;gflags=R</li><br/></ol><br/>Details of Yahoo Geo tools  (GeoPlanet Guide)<br/><ul><br/>	<li>http://developer.yahoo.com/geo/geoplanet/guide/concepts.html</li><br/>	<li>http://developer.yahoo.com/geo/geoplanet/guide/api_docs.html</li><br/></ul><br/>Where On Earth Identifiers  (WOEID)<br/><br/>Its a 32bit identifier, which is unique and non-repeated. This has a parent-child relationship to places, which makes it human understandable in the meantime useful for automated systems.<br/><br/>The summary of all available Yahoo Tools and API's provided here:  <a href="https://diaryfolio.com/yahoo-apis-and-developer-network/">https://diaryfolio.com/yahoo-apis-and-developer-network/</a><br/><br/>&nbsp;
