I had to create a sample script to convert epoch time to Human readable format.  (both ways)<br/><br/>Also from Human readable time format to Epoch.  Input is a file with "Epoch" or "Human Readable"  format and the program will convert in the other format.<br/><br/>Till now we used: http://www.epochconverter.com/ .
