I was trying to install Git into a *NIX system to for testing purposes. Hence the overall steps included<br/><ul><br/>	<li>Installing VMware into Windows XP (Host) machine</li><br/>	<li>Installing Ubuntu (Guest) into VMware</li><br/>	<li>Sharing Folder between "Host" and "Guest" machine</li><br/>	<li>Proxy protected using username and password.</li><br/>	<li>Installing "git" into Guest virtual OS</li><br/></ul><br/>Just thought of noting down the issues I faced<br/><h2><span>VMware settings and Network Adapter</span></h2><br/>I have chosen 20GB hard disk space and 1GB memory (RAM) for the virtual machine.  I've disabled Floppy from the hardware list.  Choose "NAT" in Network Adapter and share host's IP address<br/><h2><span>Ubuntu Installation and 3D acceleration Issues</span></h2><br/>After installing Ubuntu 12.04, 12.10 and 13.04 (tried all), I found that Ubuntu desktop showed blank with no Icons. The desktop had no visible sidebar nor any menu options. These were enabled and active but corrupted and blacked out.   The fix is to disable "3D graphics" option within VMware.<br/><ul><br/>	<li>Shutdown Guest (Ubuntu) OS</li><br/>	<li>In VMware Menu bar -&gt; VM -&gt; Hardware -&gt;Display -&gt; Disable "Accelerate 3D graphics"</li><br/>	<li>Now restart Guest (Ubuntu) OS.</li><br/></ul><br/><h2><span> VMware shared folder to Ubuntu</span></h2><br/>By default , the share folder is disabled. Enable it and provide a "non" networked location (local Filesystem) directory.  Afterwards, restart Guest OS (Ubuntu) and when u press "df -k", it should show "/mnt/hgfs". This one should have the shared filesystems<br/><h2><span>Work Environment and proxy protected external connection</span></h2><br/>After installing Ubuntu as Guest OS, I had to install "git" and other programs. When I ran "<em>sudo apt-get install git</em>", it gave errors. This was related to Guest OS (Ubuntu) unable to access internet.  The best way to start is to run "<em>sudo apt-get update</em>" but it also gave errors due to error in connection.  Ubuntu provides system wide enabling of proxy/userid/password. This can be done by clicking on <strong>"System Settings" (Spanner icon) -&gt; Hardware -&gt; Network -&gt; Network Proxy -&gt; Use "Manual Method"</strong> -&gt; Put your HTTP &amp; HTTPS proxy . The format is "userid:passwd@proxyhost"  and enter the port number.  "<strong>Apply System Wide</strong>".<br/><br/>This will not enable in certain software like Firefox (which you need to add manually). Once i re-ran "<em>sudo apt-get update</em>" it worked fine for 50%, but started failing "407 Proxy Authentication Required". You could solve this completely by editing  "<strong>/etc/apt/apt.conf</strong>" file. Use "vi" or "gedit" editor with root permissions.  The file should already have  "Acquire::http::Proxy "http://proxyhost:port/";" in its entry. Edit this to "<strong>Acquire::http::Proxy "http://username:passwd@proxyhost:port/";</strong> " <a href="http://askubuntu.com/questions/88976/407-proxy-authentication-required">format </a>.  Close the "terminal" and restart it and try running "<em>sudo apt-get update</em>" which should work fine !!<br/><br/>&nbsp;
