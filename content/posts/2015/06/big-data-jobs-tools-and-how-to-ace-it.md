<h3>
Big Data : Overview of Structure and Jobs&nbsp;</h3>
The demand for big data resources have increased dramatically in past few years. The requirements to create and get most out of "Big Data" environment is classified into 3 tiers<br />
<br />
<ul>
<a href="/assets/images/original/2015/06/big-data-jobs-tools-and-how-to-ace-it/bigData.jpg" imageanchor="1"><img border="0" src="/assets/images/original/2015/06/big-data-jobs-tools-and-how-to-ace-it/bigData.jpg" /></a>
<li>Base Layer - DevOps and Infrastructure</li>
<li>Mid &nbsp;Layer - Understanding &amp; manipulating data</li>
<li>Front Layer - Analytics, data science</li>
</ul>
I feel the jobs surrounding "Big Data" would also ultimately reflect this. Learning Big Data should be also based on these tiers.<br />
<br />
<h3>
Software Suite/Tools</h3>
<h4>
<u>
Base Layer - Summary</u></h4>
<div>
This layer forms the core infrastructure of "big data" platform and should be horizontally scalable.</div>
<div>
<ul>
<li>OS - Linux is the way forward for big data technologies. RedHat, SuSe, Ubuntu, CentOS</li>
<li>Distributed Computing tools/software - Hadoop, Splunk</li>
<li>Data Storage - Splunk, MongoDB, Apache Cassandra</li>
<li>Configuration management - Ansible, Puppet, Chef</li>
<li>Others - Networking knowledge, Version Control (Git)</li>
</ul>
<h4>
<u>
Mid Layer - Summary</u></h4>
</div>
<div>
This layer forms the engineering role of the project with focus on data mining, normalisation etc.</div>
<div>
<ul>
<li>Regex (Regular Expression) Knowledge and machine learning</li>
<li>Various Application system knowledge to understand data</li>
<li>Data normalisation techniques, data enrichment, integration to external data stores</li>
<li>Technologies - Java, Scala, Splunk Search language, python, NoSQL,JSON</li>
<li>Tools - Apache Spark, Splunk, Mahout</li>
<li>Web Development - jQuery, AngularJS, D3.js</li>
</ul>
</div>
<div>
<div>
<h4>
<u>
Front Layer - Summary</u></h4>
</div>
</div>
<div>
This layer forms the end-user experience, business interaction experience</div>
<div>
<ul>
<li>Business Analysis - Requirement gathering, Data availability etc.</li>
<li>Web Development - Analytics, Visualisation techniques, D3.js, mathematical modelling etc.</li>
<li>Data Science - Data co-relation, regular expression, statistics and data modelling</li>
<li>Tools - Apache Ambari, Splunk, D3.js, XML/JSON formats</li>
</ul>
</div>
<div>
<h3>
Big Data Jobs</h3>
The key thing here is to concentrate on one the above layers/tiers. Depending on the flavour of your previous experience it would be quite easy to fit your profile into one of the above Tiers.<br />
<h3>
Software Suite/Tools</h3>
<ul>
<li>Apache Products (Hadoop suite, Spark, Ambari) are so varied and flexible. But return on Investment (ROI) is poor in initial years and takes time and effort to create a fully fledged system. The integration of Apache products need to be designed and upgrade plan should be well in place as products change quite often.</li>
<li>Splunk on the other hand encompasses all into a single suite. Splunk is not a free product, but licensing is based on data volume you index. ROI is very quick and great and can build Proof of Concept systems (POCs) immediately.</li>
</ul>
</div>
