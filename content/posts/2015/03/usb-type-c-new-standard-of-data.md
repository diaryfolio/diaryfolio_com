USB-C aka USB Type-C aka USB 3.1 is the new standard which OEM companies going to adopt from 2014 onwards. This standard has been given a great boost by <a href="http://www.apple.com/macbook/design/" target="_blank">Apple MacBook 2015 edition</a> thus paving way for next generation data transfer speeds and compatibility. Apple Macbook now has a single external interface ( A SINGLE port !! can you believe it !!) which shows the flexibility of USB3.1 .<br />

<h3>
Pros of USB Type-C (USB 3.1)</h3>
<ul>
<li>High Data Signalling Speed of 10Gbps (i.e Twice that of USB3.0 and 16x of USB2.0)</li>
<li>Industry Standard and adopted by all major OEMs</li>
<li>Reversible plug orientation (i.e. you can plug USB cable in any direction)</li>
<li>Backward compatible with USB 3.0 and USB 2.0</li>
<li>Various Power Profiles and <a href="http://www.usb.org/developers/powerdelivery/" target="_blank">can deliver upto 100W @20V(5A)</a></li>
<li>Multiple channels of data flow thus be used at both host and device side</li>
<li>Can replace multiple other data transfer cables (Thunderbolt, USB TypeB etc)</li>
</ul>
