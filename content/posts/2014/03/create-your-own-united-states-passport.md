American Passport Photo requires <span><strong>50.8mm x 50.8mm (2" x 2")</strong></span> photos. So do Overseas citizen of India application (<span><strong>OCI photo</strong></span>). As you are all aware, GIMP is very powerful too for image editing. &nbsp;This article provides a very cost effective way to print&nbsp;<strong>&nbsp;(2" x 2")</strong>&nbsp;photos from nearby print enabled stores (like Boots in the UK etc..) for less than 30pence (40 cents approx) !! &nbsp;For further details on United states photo requirement, please read <a href="http://london.usembassy.gov/cons_new/acs/passports/photo.html" target="_blank">this article</a><br />

<h3>
Step by step method of editing photo</h3>
<ul>
<li>From your gimp “<strong>Toolbox</strong>”, click the “<em>Rectangular Select</em>” tool. (Ensure that the ”Fixed Aspect Ratio” is unticked). &nbsp;Draw a small rectangle surrounding your face. In the left hand-pane, choose Size, Enter width=510 px and height=510 px. &nbsp;(or a ratio of this) and then select <strong>“Fixed Aspect Ratio”</strong>. &nbsp;You will see a rectangle area in the image to be adjusted accordingly</li>
<li>Using mouse select area with your face and satisfy all conditions of your photo (like 80% face, shoulder visible etc..). Read relevant requirements.</li>
<li>Once ready, Crop the image. &nbsp; from GIMP Menu &nbsp;<strong>Image -&gt; Crop to Selection</strong></li>
<li>Now resize the image. &nbsp;From GIMP menu, &nbsp;Image -&gt; Scale Image and select <strong>width=1089 px</strong> (Automatically height becomes 1089 px as its 1:1 aspect ratio). Copy this image (Control-C)</li>
<li>Now open a new Window (Control key + N) with width and height &nbsp;= <strong>1120 px</strong></li>
<li>Paste the previous image into this new image and click on the white border surrounding to merge.</li>
<li>Ensure you clicked on the white border. Then Select <strong>Filters -&gt;Map -&gt; Tile</strong> from GIMP window. &nbsp;”Tile to new size”, then &nbsp;<span><strong>disconnect the chain symbol</strong></span> (by clicking on it) and set the <strong>width = 3256 px</strong> &amp; <strong>height = 2184 px</strong></li>
<li>Result would show you 8 photos. (But only<strong> 2 of them will be perfect</strong>)</li>
<li>Now save as a JPG file using "<strong>File -&gt; Export To</strong> &nbsp;”, then save it as with jpg extension with “USpassportTile.jpg”</li>
<li>Save the .jpg file to a memory stick.</li>
<li>My local “BOOTS” shop allows USB memory stick, SD card, CD and many other storage to be used . Select 6×4 inch prints, which should print 2 photos. (Select no margins at boots) &nbsp; or Alternatively you could print from your home printer: &nbsp;From GIMP Image -&gt; Print-size , width = 6 inches, height = 4 inches. Then print with File -&gt;Print</li>
</ul>
